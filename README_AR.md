# HARES AI – حارس | PWA Starter

## ما تتضمنه الحزمة
- واجهة عربية قابلة للإضافة إلى الشاشة الرئيسية بعد نشرها على HTTPS.
- فحص يدوي تجريبي للرسائل والروابط بقواعد محلية بسيطة.
- Service Worker وWeb App Manifest للتثبيت كـ PWA.

## ما لا تفعله هذه النسخة
- لا تحجب المواقع ولا تفحصها في الخلفية.
- لا تقرأ رسائل SMS أو WhatsApp أو محتوى التطبيقات الأخرى تلقائياً.
- لا تستخدم نموذج ذكاء اصطناعي أو قواعد بيانات تهديدات مباشرة.
- نتيجة الفحص ليست حكماً أمنياً موثوقاً.

## النشر والتثبيت على iPhone
1. ارفع جميع الملفات إلى استضافة تدعم HTTPS (مثلاً استضافة صفحات ثابتة).
2. افتح رابط الموقع المنشور في Safari على iPhone.
3. اضغط زر المشاركة ثم اختر Add to Home Screen / إضافة إلى الشاشة الرئيسية.
4. اضغط Add / إضافة.

## التطوير التالي
إضافة خدمة API آمنة، ومصادر سمعة نطاقات موثوقة، واختبارات أمنية، ثم تطوير تكاملات iOS الرسمية مثل Network Extension / DNS filtering بعد مراجعة أهلية الاستخدام وسياسات Apple. بناء تطبيق iOS أصلي وتوقيعه يحتاج بيئة macOS أو خدمة بناء سحابية موثوقة وحساب Apple Developer للنشر.
